# AQUILON R4 — Race Amphibian Concept

Futuristic **4.0 m × 1.5 m** four-seater race amphibian ATV with **folding wheels**.

## Open the showcase

```bash
cd aquilon-r4
python3 -m http.server 8765
```

Then open `http://localhost:8765`.

## Concept summary

| Item | Spec |
| --- | --- |
| Envelope | 4000 × 1500 mm |
| Seats | 4 × race buckets (2×2) |
| Land | 4× in-hub electric, ATV tread |
| Water | Twin waterjets; wheels fold into side pockets |
| Fold cycle | ≤ 1.8 s with sealed bay gaskets |
| Look | Graphite composite · ice-cyan accents · stealth wedge |

## Files

- `index.html` / `styles.css` / `main.js` — interactive design showcase
- `assets/` — concept renders (land, water folded, orthographic, fold detail)
